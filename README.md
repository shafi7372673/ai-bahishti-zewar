# AI بہشتی زیور (AI Bahishti Zewar)

ایک مخصوص اور مستند اسلامی شرعی سوال و جواب کا تحقیقی پلیٹ فارم، جس کا **واحد اور حتمی علمی ماخذ** حکیم الامت حضرت مولانا اشرف علی تھانویؒ کی شہرۂ آفاق تصنیف **"بہشتی زیور"** ہے۔

---

## 🌟 بنیادی اصول و شرعی ضابطہ

1. **واحد ماخذ:** تمام شرعی مسائل صرف اور صرف کتاب بہشتی زیور سے تلاش کیے جاتے ہیں۔
2. **غیر متعلقہ یا نامعلوم سوال پر واضح انکار:** اگر سوال کا جواب کتاب بہشتی زیور میں موجود نہ ہو تو سسٹم قیاس آرائی کے بجائے یہ متعین جملہ ظاہر کرتا ہے:
   > *"معذرت، فراہم کردہ کتاب بہشتی زیور میں اس سوال کا متعلقہ جواب نہیں مل سکا۔ یہ ٹول صرف اسی کتاب کی بنیاد پر جواب دیتا ہے۔"*
3. **اصل عبارت اور آسان تشریح کی علیحدگی:** ہر جواب میں کتاب کی اصل عبارت بعینہٖ لفظ بہ لفظ، اور اس کے ساتھ آسان فہم تشریح بغیر کسی شرعی حکم، شرط یا استثنا میں رد و بدل کے الگ الگ خانے میں پیش کی جاتی ہے۔
4. **تصدیق شدہ حوالہ:** ہر جواب کے ساتھ کتاب کی جلد نمبر، صفحہ نمبر، باب و فصل اور مسئلہ نمبر کا مصدقہ حوالہ ظاہر کیا جاتا ہے۔ کوئی فرضی حوالہ نہیں بنایا جاتا۔
5. **سخت بیک اینڈ گراؤنڈنگ:** AI کو بغیر تصدیق شدہ کتابی عبارت کے کوئی جواب دینے کی اجازت نہیں ہے۔ سرچ انجن پہلے کتاب میں تلاش کرتا ہے اور اسکور تصدیق کے بعد ہی جواب کی اجازت دیتا ہے۔

---

## 🛠️ تکنیکی ڈھانچہ

* **فرنٹ اینڈ:** HTML5 (RTL اردو ساخت)، CSS3 (اسلامی طرزِ تعمیر و نستعلیق فونٹ 'Noto Nastaliq Urdu')، اور جدید JavaScript (صوتی تلاش، آڈیو قرات، براؤزنگ، کاپی فیچر)۔
* **بیک اینڈ سرور:** Node.js اور Express۔
* **سرچ و ریٹریول انجن:** اردو اعراب و املا کا نارملائزر، اسٹاپ ورڈ فلٹر، مترادفات و فقہی اصطلاحات کی ڈکشنری، اور کوریج ریشو اسکورنگ الگورتھم۔
* **محفوظ API ماحول:** گوگل جیمینائی کی API کلید کو سرور کے `.env` میں محفوظ رکھا گیا ہے اور کلائنٹ پر کبھی ظاہر نہیں کیا جاتا۔ API کے بغیر بھی مکمل سسٹم ۱۰۰٪ آف لائن کام کرتا ہے۔
* **پی ڈی ایف و کارپس انڈیکسنگ:** بہشتی زیور کی پی ڈی ایف فائلوں کو پروسیس کر کے صفحات کے حساب سے مستقل محفوظ کرنے کی صلاحیت۔

## 🚀 چلانے کا طریقہ

### ۱۔ پروجیکٹ ڈائریکٹری
```bash
cd "e:\AI Bahshti Zewar"
```

### ۲۔ ڈیپینڈینسیز انسٹالیشن (اگر درکار ہو)
```bash
npm install
```

### ۳۔ سرور کا آغاز
```bash
node server.js
```

سرور چالو ہونے کے بعد براؤزر میں درج ذیل ایڈریس کھولیں:
```
http://localhost:3000
```

## 📖 خصوصیات

1. **مسئلہ تلاش کریں:** عام فہم اردو سوال لکھیں یا مائیکروفون کے ذریعے بولیں۔
2. **جلد کے لحاظ سے فلٹر:** مکمل کتاب یا مخصوص جلد (جلد ۱ تا ۸) منتخب کرنے کی سہولت۔
3. **اصل عبارت و آسان مفہوم:** دونوں حصوں کو الگ الگ اور واضح دکھایا جاتا ہے۔
4. **آڈیو فیچر:** جواب اور آسان تشریح کو اردو آواز میں سنیں۔
5. **حوالے سمیت کاپی:** ایک کلک پر مکمل حوالہ بمع اصل عبارت کلپ بورڈ میں محفوظ کریں۔
6. **کتاب کی ورق گردانی:** ڈیجیٹل کتاب کے تمام ابواب اور مسائل کی فہرست پڑھیں۔
7. **پی ڈی ایف و نیا متن محفوظ کریں:** بہشتی زیور کی کسی بھی جلد کی پی ڈی ایف اپلوڈ کریں، صفحات خودکار محفوظ ہو جائیں گے۔
